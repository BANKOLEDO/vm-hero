Optional art can be added to this folder and the page turns it into a
hand-drawn pen sketch automatically. Only use art you created or have permission
to use. The page uses original procedural sketches when these files are absent.

File names (any of .jpg/.jpeg/.png/.webp):

  keyleth.jpg   vax.jpg   vex.jpg    percy.jpg
  grog.jpg      pike.jpg  scanlan.jpg  trinket.jpg

Best results: a single character, face and shoulders visible, plain
background, roughly square or portrait orientation. Portraits missing a
file fall back to the procedural line doodle. Click any portrait on the
page to re-sketch it with a new hand jitter.
